# PhantomCraft 

PhantomCraft — desktop-приложение для управления AFK-ботами в Minecraft с авторизацией через Microsoft Account (MSA).

Бот подключается к серверу Minecraft, остаётся в игре в режиме AFK и автоматически переподключается при разрыве соединения или других сбоях.

## Возможности

- Подключение к Minecraft серверу через MSA аккаунт
- Поддержка мультиаккаунтов
- AFK-ботинг (автоматическое пребывание на сервере)
- Автоматическая отправка сообщений с настраиваемым интервалом
- Автоматическое переподключение при разрыве соединения
- Простое управление через понятный интерфейс

---

## Важно

Приложение предназначено для технических и тестовых целей. Использование на серверах может нарушать их правила — ответственность лежит на пользователе.
