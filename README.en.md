# PhantomCraft

PhantomCraft is a desktop application for managing AFK bots in Minecraft with Microsoft Account (MSA) authentication.

The bot connects to a Minecraft server, stays online in AFK mode, and automatically reconnects if the connection drops or other issues occur.

---

## Features

- Minecraft server connection via MSA account
- Multi-account support
- AFK botting (staying online on servers automatically)
- Automatic reconnection on disconnects or failures
- Simple and user-friendly interface

---

## Important

This application is intended for technical and testing purposes only. Using it on servers may violate their rules — users are fully responsible for their actions.
